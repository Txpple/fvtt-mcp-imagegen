# imagegen log: 2026-10

The dated journal of this repo, moved out of `CLAUDE.md` (which keeps the rules and one State block). One
heading per day, oldest first. Release detail is on the GitHub release notes.

## 2026-10-02

- **Battlemaps** arrived as a kind, `edit-image` only (owner request). **Nothing moves on a battlemap** (owner
  rule): the source padded to the API aspect and mapped back onto its own grid, then the drift check,
  calibrated that day on 24 live renders across 8 maps.
- **Maps ship as WebP** (the owner's call): a restyled map is 20 to 70 MB as PNG and about 4 MB as WebP; a map
  past WebP's 16383 px limit falls back to PNG.
- Released as v1.2.0 (battlemap restyles, the drift guard, WebP maps).

## 2026-10-03

- **Overland maps** arrived as a kind, `edit-image` only (owner request): the battlemap geometry with a keep
  line that locks the geography and paints out every name, marker, road, compass rose and scale bar.

## 2026-10-11 to 2026-10-14

- The `illustration-builder` skill gained a run of owner rules for maps, tiles and tokens (each commit names
  its rule; no tool changed): fine edits to a painted map are prop tiles; a token's camera angle is its base's;
  opaque patch tiles; tiles placed unlocked; light dressing passes; closing a corridor needs a fade pass;
  overhead features painted out in one pass and back as fading tiles; token bases picked by pose; weapons sized
  when they first appear; an owner-chosen pose restyled in light pose-locked passes; PC and key-NPC tokens
  drawn from words by default.
